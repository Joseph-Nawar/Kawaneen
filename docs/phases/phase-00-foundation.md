# Phase 00 — Foundation

## Status

Phase 0 defines the project identity and local engineering foundation. It does not deliver legal intelligence functionality.

## Included

- Installable `kawaneen` package with version exposure.
- `kawaneen --version` and `kawaneen doctor`.
- Pydantic Settings validation with `KAWANEEN_` overrides.
- Structlog console/JSON output integrated with standard logging.
- Tests, coverage, Ruff, Pyright, pre-commit, Makefile, and CI.
- Data ignore safeguards and version-controlled metadata directories.

## Explicitly planned, not implemented

Future phases may evaluate jurisdiction-aware corpus ingestion, Arabic document handling, NLP, source-linked retrieval, RAG, APIs, user interfaces, model selection, and vector storage. None of those capabilities should be inferred from the Phase 0 CLI or package.

## Exit evidence

The Phase 0 report records the final file map, commands, outputs, coverage, manual steps, and deviations.
