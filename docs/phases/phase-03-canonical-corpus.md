# Phase 3 — Canonical corpus construction

Phase 3 constructs exact-text canonical case and statute views, provenance mappings,
conservative statutory reconstruction metadata, reconciliation templates, and an
optional PDF/OCR routing boundary. It does not normalize Arabic, build retrieval
chunks, embed text, train models, serve APIs, or authorize public display.

The phase is complete only when all Phase 2 rows are accounted for, canonical outputs
validate, raw hashes are unchanged, the core statutory reconciliation has meaningful
completed records, and the empirical parser benchmark has actually run against
authorized pages. A missing or blocked benchmark is not a passing result. Phase 4 may
consider private parsing only under the source-specific governance decisions; no
source becomes training- or public-display-eligible through canonicalization.
