# ADR 0001: Project Identity and Scope

## Decision

Use `kawaneen` for the display, repository, distribution, and import name. Phase 0 is foundation only.

## Context

The future product needs a stable identity while legal intelligence capabilities are still being designed. Mixing future product claims into the first scaffold would make the boundary unclear.

## Consequences

The package can be installed and tested now. Legal search, retrieval, RAG, and related infrastructure remain planned work and are not represented as working features.
