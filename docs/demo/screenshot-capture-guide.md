# Screenshot capture guide

Screenshots are presentation artifacts, not metric sources. Start the live
public demo and capture the Search, Ask, Extract, and Evaluation pages at a
consistent viewport. Use only the synthetic `KAWANEEN_DEMO` content. Preserve
the public-demo banner and limits in each relevant frame. Do not add browser
automation packages solely for capture. If GUI capture is unavailable, report
`SCREENSHOTS_MANUAL_CAPTURE_REQUIRED`; do not fabricate PNGs.
