# Saudi Board of Grievances open data

Canonical pages: [open-data description/catalogue](https://www.bog.gov.sa/EServices/OpenData/Pages/AboutOpenData.aspx), [usage policy](https://www.bog.gov.sa/EServices/OpenData/Pages/UsageGuide.aspx), and [judgments page](https://www.bog.gov.sa/ScientificContent/JudicialBlogs/Pages/JudgmentsDefault.aspx). Inspected 2026-08-06.

The catalogue describes open statistical measures such as registered, received, completed cases, judgments, and hearings. The usage guide requires source attribution and prohibits distortion. This proves aggregate open-data policy, not a reusable full-text case corpus. Judgment pages are a separate rights/access question. Decision: `metadata_only`; not a primary corpus.
