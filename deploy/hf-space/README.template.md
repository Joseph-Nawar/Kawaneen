# Kawaneen public demo

This is a deliberately reduced, retrieval-first demonstration using a small
fictional `KAWANEEN_DEMO` corpus. It contains no real legislation, no Saudi
legal source text, and no legal advice. It uses precomputed
`intfloat/multilingual-e5-small` corpus vectors, small BM25/RRF retrieval, and
deterministic exact evidence snippets. It does not run an LLM, Ollama, Qdrant,
or MLflow. Query and extraction limits are intentionally strict.

This bundle is prepared but not published. Publication requires explicit user
approval: `NOT_PUBLISHED_USER_APPROVAL_REQUIRED`.
