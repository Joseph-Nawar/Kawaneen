# Security policy

Kawaneen is a portfolio/research project, not an enterprise service. Do not
include private legal text, customer data, credentials, tokens, or sensitive
paths in vulnerability reports or issues.

If GitHub private vulnerability reporting is enabled for this repository, use
that channel for suspected credential exposure or security defects. If it is
not available, open a minimal non-sensitive issue requesting private
coordination; do not disclose exploit details or private data publicly. No
enterprise support or SLA is offered.
