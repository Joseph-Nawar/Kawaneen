# Canonical interim outputs

Local canonical Parquet outputs are generated by `kawaneen corpus build` under
`data/interim/canonical/<source>/<version>/`. This directory is ignored by Git.

Outputs preserve source text exactly and are not a normalized corpus, retrieval index,
training set, public corpus, or legal-authority determination.

Phase 4 normalization views are separate private derived artifacts under
`artifacts/private/phase4_normalization/`. They preserve `display_text` exactly and
add a policy-versioned `search_text`; they never overwrite these canonical outputs.
